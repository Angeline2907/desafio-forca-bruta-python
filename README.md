# Desafio de Força Bruta em Python

Este repositório contém a resolução do desafio de ataque de força bruta, adaptado para trabalhar com senhas curtas (de até 3 caracteres) e exibir o progresso de cada tentativa na tela.

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* Biblioteca integrada `itertools`

## 🚀 Como Executar o Projeto
1. Clone o repositório ou baixe os arquivos.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:
   ```bash
   python main.py
   ```
